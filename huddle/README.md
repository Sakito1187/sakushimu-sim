# ハドルのシミュレーション

Waters, Blanchette, Kim (2012) "Modeling Huddling Penguins", PLoS ONE 7(11): e50277（https://pmc.ncbi.nlm.nih.gov/articles/PMC3500382）を Python で作り直したもの。作シミュ #01 の計算はすべてここで行った。

## モデル（論文と同じところ）

- ペンギンは六角形のマスに 1 羽ずつ。群れの形は、3 羽ずつ互いにとなり合う三角形をすべて合わせた多角形（= ふちの子の中心を結んだ形）
- 群れのまわりの風はポテンシャル流（粘りと渦のない定常の流れ）。風は左から
- 温度は定常の移流拡散 `u·∇T = (1/Pe)∇²T`。ペンギン = 1、遠く = 0
- 1 羽ずつの熱の失い方 Q は、その子の受けもつふち（となりの子との中点から中点まで）を通って出ていく熱
- 1 手に 1 羽だけ動く。ゆらぎを足した Q が最大のふちの子が、Q が最小のふちの子と、そのとなりで Q が最小の子の、両方にとなり合う空いたマスへ移る
- はじめは 5 羽から、2 羽以上ととなり合う空いたマスへ 1 羽ずつ足して作る

## 論文と違うところ

| 論文 | ここ | 理由 |
|---|---|---|
| 群れの外を単位円の外に写して（Schwarz-Christoffel 写像）解く | 直交格子（0.25 羽分）の有限体積法で同じ方程式を解く | 写像の数値計算（SC Toolbox）が MATLAB 用のため |
| Pe は単位円（= 群れの大きさ）が基準 | 群れと同じ面積の円の半径 R を基準に `Pe = U R / D` | 写像した先の大きさに合わせるため。ペンギン 1 羽を基準にすると、同じ Pe でも風が約 5 倍強くなり、論文よりずっと細長くなった |
| 行き先の決め方は図で説明されている | 2 羽の両方にとなり合う空いたマスがなければ、1 羽目のとなりで、となりがいちばん多い空いたマス | 論文の本文に書かれていない場合のため |
| 2 羽以上のとなりを保つ | とび出た子（となりの 2 羽どうしが接していない）は、となりとの間を太さ 0.5 の線で結んで、熱を受けるようにする | 多角形からはみ出し、熱が 0 になって行き来をくり返したため |
| ゆらぎの大きさの基準 | 1 羽だけのときの Q（この格子では粗い） | 論文の式が図の中にあり、本文から読めないため。ゆらぎの値は論文と同じ大きさではない |

比べるための「でたらめな群れ」（`--select random`）は論文にない。ふちの子をでたらめに選び、三角形になる空いたマスへでたらめに動かす。

## 確かめた結果（2026-11-17）

形（100 羽・Pe = 10・ゆらぎなし、`n100_pe10`）:
- 風上がけずられて丸くなり、横が平らになる。250 手ほどで形が落ち着き、厚さが一定（約 5 列）になる。長さ / 厚さ ≈ 3.5
- 群れは風下へ進みつづける（400 手で重心が約 57 羽分）
- 論文: 「100 手ほどで横が平らで両端が丸い形になり、そのあとは厚さを保って風下へゆっくり進む」。形が落ち着くまでの手数は論文より多い

公平さ（100 羽・Pe = 10・2000 手、最初の 300 手は数えない。`fairness.py`）:

| 群れ | 動く番の間隔のばらつき | Q の合計の変動係数 |
|---|---|---|
| 自分勝手・ゆらぎ 0 | 0.07 | 0.045 |
| 自分勝手・ゆらぎ 0.1 | 0.24 | 0.21 |
| 自分勝手・ゆらぎ 0.3 | 0.49 | 0.19 |
| 自分勝手・ゆらぎ 1 | 0.90 | 0.23 |
| 自分勝手・ゆらぎ 3 | 1.31 | 0.36 |
| でたらめ（種 0 / 1） | 0.89 / 0.94 | 0.39 / 0.43 |

間隔のばらつきは、でたらめに選んだときの理論値（幾何分布）が 0.99。論文: 「ゆらぎが小さいと、間隔のばらつきはでたらめよりずっと小さい。ゆらぎを大きくしても熱の分け合いはほぼ公平」。ここでも、ゆらぎが小さいほど間隔がそろい、Q の合計はどの大きさのゆらぎでもでたらめより平ら。

風の強さと形（400 羽・ゆらぎなし・2400 手、`pe_n400_<Pe>`）:

| Pe | 3 | 10 | 30 | 100 |
|---|---|---|---|---|
| 長さ / 厚さ（落ち着いたあと） | 1.3 | 2.4 | 6.0 | 18.3 |

論文: 「風が強いほど細く長くなる。Pe ≈ 100 で長さ / 厚さ ≈ 8」。強いほど細長くなる傾向は合うが、同じ細さになるのは、ここでは Pe ≈ 30〜40。風の強さの基準（Pe の長さ）が論文と 3 倍ほどずれている。論文の基準は写像した先の大きさで、細長い群れほど「同じ面積の円の半径」より大きくなるため。そのため動画では Pe の数字を言わず、「風が強いと細長くなる」とだけ言っている。

全体の図: `out/summary.png`（`out/` の図は作り直せる）

## v3 の実験（2026-11-19。論文にない、作者が足したもの）

すべて 150 羽・Pe = 10・2000 手で、最初の 300 手は数えない。「差」は熱の合計の上位 1 割と下位 1 割の比（90 パーセンタイル / 10 パーセンタイル）、「全体の寒さ」は 1 羽 1 手あたりの Q の平均を、だれも動かない群れ（はじめの形のまま）で割ったもの。

| 群れ | 実行 | 差 | 全体の寒さ | 変動係数 |
|---|---|---|---|---|
| だれも動かない | `v_selfish` の 0 手目 | 97 羽がゼロ・風上の 15 羽が 59% | 1 | 1.94 |
| 自分勝手（ゆらぎ 0.1） | `v_selfish` | 2.0 | 1.05 | 0.26 |
| くじびき | `v_random` | 4.6 | 2.29 | 0.52 |
| 思いやり | `v_kind`（`--select kind`） | 1.3 | 7.23 | 0.15 |

- 思いやり（`select="kind"`）: いちばん暖かいふちの子が、いちばん寒い子のとなりの空いたマスのうち、いちばん風上へ。群れは風上へ 2 列ほどの線にほどけ、そのあと切れ切れになる（`out/kind_shapes.png`）。行き先がない手（620 手）は動かない
- ずるい子（`--init v_selfish:400 --freeze auto:center`、`v_cheat`）: 真ん中の子は 80 手目に初めて熱をうばわれ（風上のふち）、113 手目に群れからはぐれる。80〜112 手のあいだは、ほかのふちの子の平均の 4.4 倍、はぐれたあとは 13.7 倍。300〜1200 手の熱の合計は群れの平均の 33 倍
- 寒さのまちがい（ゆらぎ）:

| ゆらぎ | 0 | 0.1 | 0.3 | 1 | 3 | くじびき |
|---|---|---|---|---|---|---|
| 番の間隔のばらつき | 0.07 | 0.24 | 0.47 | 0.87 | 1.24 | 0.87 |
| 差 | 4.5 | 2.0 | 2.0 | 2.0 | 3.6 | 4.6 |

  ゆらぎ 0 で不公平になるのは、通り道が毎周同じになって、寒い道の子と暖かい道の子に分かれるため（前半 850 手と後半 850 手の熱の合計の相関 0.99。ゆらぎ 0.1 では 0.05）。羽数と種で確かめた:

| | 100 羽 | 150 羽（種 0 / 1 / 2） | 200 羽 |
|---|---|---|---|
| ゆらぎ 0 の変動係数 | 0.045 | 0.68 / 0.68 / 0.69 | 0.49 |
| ゆらぎ 0.1 の変動係数 | 0.21 | 0.26 / 0.27 / 0.26 | 0.31 |

  論文は「ゆらぎの大きさによらずほぼ公平」。150 羽・200 羽のゆらぎ 0 だけが合わない。作り直したときのちがい（格子・行き先の決め方）によるものかもしれない
- 1 羽の 1 周: `v_selfish` の 127 番は 402 手目と 539 手目に動き、そのあいだの 8 割は Q = 0（群れの中）

## 使い方

```
uv run python run.py --n 100 --pe 10 --noise 0 --steps 400 --name n100_pe10 --fields 50   # out/n100_pe10.npz
uv run python plot.py n100_pe10                                                           # 形の移り変わりと重心・縦横比の図
uv run python run.py --n 150 --noise 0.1 --steps 2000 --select kind --name v_kind          # 思いやりの群れ
uv run python run.py --n 150 --noise 0.1 --steps 1200 --init v_selfish:400 --freeze auto:center --name v_cheat   # ずるい子
uv run python fairness.py f_n0 f_rand                                                     # 公平さ
```

動画で使った条件: `v_selfish`（150 羽・Pe 10・ゆらぎ 0.1・2000 手）、`v_random`（150 羽・でたらめ・2000 手）、`pe_n400_3` / `pe_n400_30`（400 羽・2400 手）。

`out/` は git に入れない。numpy・scipy・matplotlib を使う（バージョンは `../pyproject.toml` と `../uv.lock`）。
